# 🛡️ InsureTrack – Insurance Claim Management System

InsureTrack is a Spring Boot-based Insurance Claim Management System designed to manage insurance policies, clients, and claims through secure REST APIs.

The project demonstrates CRUD operations, entity relationships, validation, exception handling, and authentication & authorization using Spring Security.

---

## 🚀 Features

- 🔐 Authentication & Authorization using Spring Security
- 👤 Client Management
- 📋 Insurance Policy Management
- 📝 Insurance Claim Management
- 🔄 Complete CRUD Operations
- 🔗 Entity Relationships using JPA
- ✅ Request Validation
- ⚠️ Global Exception Handling
- 🚫 404 Not Found Handling
- 🌐 RESTful APIs
- 🧪 API Testing using Postman
- 🗄️ MySQL Database
